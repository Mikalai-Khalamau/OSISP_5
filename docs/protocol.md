# Описание протокола

Сервер принимает TCP-соединения на `127.0.0.1:20113` и обрабатывает один
HTTP-подобный запрос на соединение. Запрос имеет вид:

```text
<METHOD> <PATH> HTTP/1.1\r\n
Host: <value>\r\n
\r\n
```

Поддерживаются методы `GET` и `HEAD`. Для успешного ответа сервер возвращает
статус `200`, `Content-Type`, точный `Content-Length` и `Connection: close`.
Для `HEAD` заголовки совпадают с `GET`, но тело не передаётся.

Ошибки протокола обозначаются статусами `400 Bad Request`,
`404 Not Found` и `405 Method Not Allowed`. Путь нормализуется и проверяется
относительно каталога `www`; выход за его пределы запрещён. Размер входных
заголовков ограничен, а каждый клиент обслуживается в отдельном потоке.
